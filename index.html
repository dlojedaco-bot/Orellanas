Conexión con Airtable

Pega tu token personal para leer y escribir en tu base. Se guarda solo en este dispositivo.

Cómo crear tu token: en airtable.com entra a Builder hub → Personal access tokens → crea uno con permisos data.records:read, data.records:write y schema.bases:read, y dale acceso a la base “Cultivo de Orellanas”. Cualquiera con este token puede entrar a tu base, así que no compartas este archivo con el token puesto.
